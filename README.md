# Little Lemon - Website Project

## Overview

Little Lemon is a web application that provides a platform for users to explore and book restaurant reservations. The app includes various pages such as a menu, booking page, and information about the restaurant. It was built with the purpose of learning web development concepts and connecting users to a restaurant's reservation system.

## Features

- **Menu page**: Displays a list of dishes offered by the restaurant.
- **Booking page**: Allows users to select a date and time to make a reservation.
- **API integration**: Fetches available reservation times from an external API.
- **Responsive design**: Optimized for mobile and desktop views.

## Tech Stack

- React, JavaScript, HTML, CSS
